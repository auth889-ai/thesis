Advanced Traffic Demand Generation in SUMO: ML-based Prediction of Flow Rate based on Real-world Measured Datasets

Full text author-uploaded অবস্থায় পাওয়া যাচ্ছে।

এটিকে “পৃথিবীর সর্বশ্রেষ্ঠ paper” বলা যাবে না। কিন্তু তোমার exact requirement শেখার জন্য সবচেয়ে practical recent starting paper।

Paperটি আসলে কী করেছে?

এটি এই কাজ করেনি:

SUMO data → ML model → prediction

এটি করেছে:

Real historical traffic dataset
            ↓
ML দিয়ে traffic flow prediction
            ↓
Predicted traffic flow SUMO-তে দেওয়া
            ↓
Realistic city traffic simulation
            ↓
Real traffic count-এর সঙ্গে comparison

অর্থাৎ:

ML আগে traffic flow predict করেছে, তারপর SUMO সেই predicted flow ব্যবহার করে virtual traffic তৈরি করেছে।

এটাই paper, dataset, code এবং SUMO-কে সবচেয়ে পরিষ্কারভাবে connect করে।

Step-by-step concept
Step 1: Dataset

Authors UTD19 real-world traffic dataset ব্যবহার করেছেন।

Datasetটিতে ছিল:

৪০টি শহর
২০,০০০-এর বেশি stationary traffic detector
সাধারণত প্রতি ৩–৫ মিনিটের traffic measurements
detector location
road information
vehicle flow/count information

তারপর Berlin-এর আলাদা traffic-count dataset ব্যবহার করে result verify করেছেন। Berlin dataset-এ ২৪০টির বেশি detector থেকে vehicle count, vehicle type এবং speed record করা হয়েছিল।

Step 2: ML input

Modelকে এমন information দেওয়া হয়েছে:

Time interval
Detector/Road ID
Road length
Road type
Number of lanes
Speed limit
City information
Population-related information
Previous/known traffic patterns
Step 3: ML output

Model predict করেছে:

Traffic flow
= একটি road/lane দিয়ে নির্দিষ্ট সময়ে কত vehicle যাবে

উদাহরণ:

8:00–9:00
Road A
Predicted flow = 143 vehicles/hour

Paper-এর processed data example-এ interval, road/detector attributes এবং target flow ব্যবহার করা হয়েছে।

Step 4: কোন ML models?

Authors compare করেছেন:

Linear Regression
Linear Support Vector Regression
Random Forest Regression

খুব গুরুত্বপূর্ণ:

Paperটিতে Deep Learning নেই।

এখানেই তোমার thesis contribution আসতে পারে:

Paper-এর models:
Linear Regression
SVR
Random Forest

তোমার additional models:
XGBoost
LSTM
Step 5: SUMO কী করেছে?

ML model traffic flow predict করার পরে authors:

OpenStreetMap থেকে Berlin road network নিয়েছেন
SUMO network তৈরি করেছেন
randomTrips.py দিয়ে possible trips তৈরি করেছেন
duarouter দিয়ে trips থেকে full routes তৈরি করেছেন
routeSampler.py দিয়ে predicted traffic count অনুযায়ী routes calibrate করেছেন
SUMO-তে ২৪ ঘণ্টার traffic simulation চালিয়েছেন

Flow:

Predicted traffic count
        ↓
routeSampler.py
        ↓
SUMO vehicle routes
        ↓
SUMO simulation
        ↓
Simulated traffic count
Step 6: Final result

Authors Berlin-এর ২৪ ঘণ্টার simulation-এ প্রায় ১.২ million vehicles generate করেছেন। তাদের report অনুযায়ী monitored lanes-এর ৮৫%-এর বেশি ক্ষেত্রে predicted/simulated count-এর mismatch পাঁচটির কম vehicle ছিল।

Paperটির input–output একসঙ্গে
অংশ	Input	Output
ML model	Historical traffic ও road features	Predicted vehicle flow
SUMO	Road network + predicted vehicle flow	Virtual traffic simulation
Evaluation	Simulated count + real count	Traffic-count mismatch
তোমার DL extension	Previous traffic sequence	Future traffic flow
