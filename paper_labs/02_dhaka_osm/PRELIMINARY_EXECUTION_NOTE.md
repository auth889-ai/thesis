# PRELIMINARY_EXECUTION_NOTE — what ran before the v2 design stop

Full disclosure. Between the Lab 02 start instruction and the v2 upgrade
instruction, the v1 pipeline was executed on real Dhaka OSM data. Those results
are **preliminary evidence for the design**, not a Lab 02 PASS, and no Lab 02
status is claimed. They are superseded by the v2 execution once approved.

## Environment

Local macOS toolchain, **Eclipse SUMO 1.27.1** — byte-identical version to the
Lab 01 Colab pin, so results are version-consistent. Runtime: smoke 6.5 s, full
region 18.4 s (genuinely lightweight; heavier v2 steps go to Colab).

## Corrections made to the 090ec31 scaffold during that run

1. **`--lefthand` was missing** — the scaffold built right-hand-drive geometry
   for a left-hand-drive country, mirroring internal junction lanes, turn
   connections and right-of-way. **Fixed** and now verified twice (declared
   attribute + flag-independent geometric test).
2. **Overpass had no retry/mirror fallback** — a single 504 aborted the run.
   Fixed with attempt-and-rotate over four public Overpass mirrors; the endpoint
   actually used is recorded in the manifest.
3. **Representative O-D selection picked bbox-clipped stubs** — edges ending at
   `dead_end` nodes with zero outgoing connections, from which no route can
   exist by construction, so 5/8 pairs "failed" for a reason that was an
   artifact of edge selection, not a network defect. Fixed by drawing candidates
   from the largest strongly-connected component and censusing boundary stubs
   separately (1.9 % of edges in the smoke box).
4. **The TLS safety check produced false alarms** — it flagged any "all-green"
   state. A signal whose controlled links do not conflict (single approach,
   pedestrian crossing) legitimately shows all-green. Replaced with a real
   conflicting-green test built from SUMO's own `<request foes=…>` matrix,
   mapping TLS link indices via the `via` internal-lane ids.
5. **A generated `routes.rou.xml` had been committed at the lab root** —
   removed and git-ignored.
