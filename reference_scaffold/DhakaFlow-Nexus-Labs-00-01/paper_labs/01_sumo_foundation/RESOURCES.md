## Canonical SUMO paper

**Microscopic Traffic Simulation using SUMO** — Alvarez Lopez et al., ITSC 2018

- DOI: https://doi.org/10.1109/ITSC.2018.8569938
- Open-access DLR record: https://elib.dlr.de/127994/
- Open PDF from DLR repository: https://elib.dlr.de/127994/1/08569938.pdf
- SUMO publications page: https://sumo.dlr.de/docs/Publications.html

SUMO documentation explicitly asks users to cite this paper as the current reference publication.
