# pipeline/networking/ — V2X chapter (Eclipse MOSAIC 25.2, unmodified, on the registered Dhaka R1 scenario)

- `penetration_sweep.py` — copies `artifacts/mosaic_dhaka/dhaka_r1` to `scenarios/dhaka_r1_p{P}_s{SEED}/`, sets the V2X penetration P via the mapping knob (`mapping_config.json` → `typeDistributions.DEFAULT_VEHTYPE` = weighted prototypes {AdHoc: WeatherWarningApp+SlowDownApp, weight P} / {Unequipped: SlowDownApp, weight 1−P}, `fixedOrder=false` so the scenario `randomSeed` decides who is equipped), runs `mosaic.sh -c … -l logback_sweep.xml`, parses the output-ambassador CSV (registrations, DENM tx/rx with per-MessageId latency, trajectories), Navigation.log (route switches), SUMO tripinfo/summary, and writes `results/penetration_p{P}_s{SEED}.json` + `results/penetration.csv/.md`.
- `latency_injection.py` — added latency {0, 500, 2000, 5000 ms} × loss {0, 10, 30 %} vs. the fraction of advisories that arrive before the vehicle reaches the hazard (time budget per rerouting vehicle from the sweep; base latency = measured Barnim distribution via `research/networking/v2x_bus.py`) → `results/latency.csv/.md`.
- `logback_sweep.xml` — MOSAIC's `etc/logback.xml` with the per-vehicle app-log delegate at WARN (the reference 1000 s run wrote 37 GB of DENM reception lines; that logging, not the simulation, was the 35-min wall time — a 600 s point now takes ~20–60 s).
- Run one point: `python pipeline/networking/penetration_sweep.py --p 0.25 --seed 11 --duration 600`; full grid: `--all --seeds 11 22 33 --skip-done`; rebuild tables: `--aggregate`; fix travel-time split from kept logs: `--refresh-tripinfo`.
- `results/logs/<point>/` keeps the small MOSAIC logs (MOSAIC/Navigation/Mapping/Traffic/Communication/Environment); the multi-GB `visualizer.csv` is deleted after parsing; `scenarios/` and `results/logs/` are git-ignored.
- Definitions: equipped = registered with WeatherWarningApp; delivery ratio = distinct DENM receivers / equipped; latency = t_rx − t_tx per MessageId (SNS ad-hoc ITS-G5, multi-hop TTL 20); route switches = CentralNavigationComponent "Change to route" lines; travel time = SUMO tripinfo of finished trips (equipped vs unequipped via the Traffic.log id map).
- Hazard: TRACTION_HAZARD/ICE rectangle at Karwan Bazar (`environment_config.json`), active for the whole run; equipped vehicles that sense it broadcast DENMs, receivers with the hazard on their route reroute through the official NavigationModule (no MOSAIC code touched, scenario configs only).
- Reference gate: `artifacts/gates/MOSAIC_DHAKA_V2X.json` (P=1, 1000 s: 2,593 receivers, 886 route switches).
